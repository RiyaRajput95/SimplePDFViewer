# 📄 Simple PDF Viewer

A simple, lightweight, and user-friendly Android application for viewing PDF documents with a clean and minimal interface.

## ✨ Features

* 📄 View PDF documents
* 🏠 Simple and clean home screen
* 👆 One-tap PDF viewing
* 📱 Dedicated PDF viewer screen
* 🧭 Simple navigation
* ⚡ Lightweight Android application
* 🎨 Clean and minimal UI

## 🛠️ Tech Stack

* **Kotlin**
* **Android SDK**
* **Gradle**
* **Material Design**
* **Android Jetpack**


## 📋 Requirements

* Android Studio
* Android SDK
* JDK
* Android device or emulator

## 🚀 Getting Started

### 1. Clone the repository

git clone https://github.com/RiyaRajput95/SimplePDFViewer.git
### 2. Open the project
Open the cloned project in **Android Studio**.

Allow Gradle to sync and wait for the project to finish loading.

### 3. Run the application

Connect an Android device or start an Android emulator.

Click **Run ▶** in Android Studio to build and launch the application.
